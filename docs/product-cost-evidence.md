# Product cost evidence
The order-date cohort uses only orders already passing package, barcode, amount, observed cost and outbound cargo checks. Sale components are grouped by exact barcode across packages. All expenses are stored in 1/10000 TL units before aggregation. Single-barcode order cargo is attributed once to that barcode. Multi-barcode freight stays at order level as unallocated shared freight. Product after-cargo result is explicitly a subset, never combined with the broader before-cargo total as if they cover the same units. Claims, returns, corrections and missing observations withhold the order. First observed costs are not proof of actual historical purchase cost. No VAT/service/withholding/advertising allocations, no actual net-profit claim. The automatic finance/order sync supplies inputs after host setup.
