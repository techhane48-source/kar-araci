# Automatic commission replacement
Official contract https://developers.trendyol.com/docs/cari-hesap-ekstresi-entegrasyonu and https://developers.trendyol.com/reference/getsettlements . Use order-line rate estimates only before statement evidence arrives. Match seller binding, domestic scope, raw ID, order/package, barcode amounts, gross = commission + revenue (1 kuruş tolerance per row), package and barcode totals (5 kuruş). Replace the commission once, not add it to the old estimate. Invalid or partial evidence, claims, non-Sale movements and unknown package adjustments withhold estimated profit. Query all stored movements by order in batches, regardless of transaction date. No user interaction. Commission is a Sale statement amount, not independent confirmation of invoice VAT or final net profit; existing VAT assumption remains. Service fee can be filtered using transactionSubType=PlatformServiceFee (official 18 March 2026 changelog https://developers.trendyol.com/changelog/changelog); this is already recorded at store level. No invented per-order invoice allocation. Synthetic tests; live confirmation pending. No marketplace writes.
