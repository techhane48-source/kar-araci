# Period finance
Official Trendyol otherfinancials supports transactionType=DeductionInvoices and transactionSubType=PlatformServiceFee (2026-03-18 changelog). https://developers.trendyol.com/docs/cari-hesap-ekstresi-entegrasyonu . The subset is fetched alongside unfiltered deduction invoices for each date slice, matched by exact document ID, seller, amounts and scope. It is not inserted as a second financial row. Missing/changed results fail the slice; service-fee query coverage is recorded separately. Schema v2 adds nullable classification; old rows are unclassified until refreshed.

Period report groups existing raw domestic seller-scoped records by transaction date; includes withholding, financing, payouts, commission reconciliation, invoices and explicitly filtered fees. Advertising/influencer text is only a candidate, not verified spend. No aggregation of invoice details on top of invoice totals. Zero or missing movements are not evidence of zero expense. No true period profit without accrual accounting, VAT, actual cost and remaining live-data verification.
