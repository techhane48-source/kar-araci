# Return inventory evidence
Accepted claim items are matched to the outbound package, order, line ID and barcode. All accepted items on the same original line (not just the selected report period) must fit the sold quantity. The operator records physical inspection of one item: resellable (full recorded cost recovered), unusable (zero), or partial recovery at explicit cost-basis value below recorded cost. The record is tied to claim identity, last-modified timestamp and cost basis; changes invalidate the result until inspected again. Unknowns are not zero. These are user-entered inventory impairment components, not independent warehouse proof or total return loss. Refund, VAT, service, outbound/return cargo, packaging and other expenses require independent evidence; no package-level fees are allocated by guess. Schema version 3, isolated tests. No marketplace writes, return acceptance, or live stock updates.
