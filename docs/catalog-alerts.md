# Catalog alert centre
Catalog profit is a modeled estimate. Missing cost or price does not produce a loss. Negative profit and nonnegative below-target estimates are disjoint. Stock and sale price observations from Trendyol are tracked independently. Missing fields clear confidence; no list-price substitution for a missing sale price. Existing rows need a successful refresh. The 24-hour threshold is app policy. Zero commission is valid but flagged for review. Desi is a user-entered comparison and return rate is an assumption. CSV exports matching products; the UI previews 50 per category. Dashboard shows unknown store expenses and exact net profit as unavailable. No live writes or notifications. Live API validation remains required.
