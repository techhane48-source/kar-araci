# Product statement movement report

Official source: https://developers.trendyol.com/docs/cari-hesap-ekstresi-entegrasyonu . The automatic settlements job supplies realized transaction records; a product report groups the stored movements by exact barcode, seller, domestic scope and transaction date. Sale and Return amount components are checked against gross credit/debt and signed commission/revenue; inconsistent rows are excluded and counted. Campaign discounts/coupons and cancellations are shown as signed seller-revenue components only, not net profit or complete promotional subsidies. Other adjustments are counted, not silently included in a net-profit estimate. Counts are movements, not units. No freight/fees/taxes or inventory costs are allocated here. Missing query coverage is visible. No additional API request or user action is necessary after scheduled sync has actually been enabled.

Public integration documentation index https://developers.trendyol.com/llms.txt and finance guide were reviewed. No verified public seller-specific upcoming campaign/commission-offer endpoint was identified; do not invent endpoints or scrape private sessions.
